# ResQ — Real-Time Disaster Management & Emergency Coordination Platform

A high-performance emergency response platform built with React, Vite, Framer Motion, Lucide icons, and modern glassmorphism. Features role-based operational command dashboards for Citizens, Volunteers, Government Officers, and System Administrators.

---

## 🚀 Quick Start

You can now run the app directly from this root directory:

```bash
# Start the development server
npm run dev
```

Then open **[http://localhost:5173/](http://localhost:5173/)** in your browser.

Alternatively, you can run directly from the app folder:
```bash
cd resq_vnext
npm run dev
```

## 🔑 Demo Access Credentials

| Role | Passkey Required? | Demo Passkey | Features Accessible |
|---|---|---|---|
| **Citizen** | No | None | Emergency SOS, Shelter Capacity, Family Safety Check-In, Incident Reporting |
| **NGO / Volunteer** | No | None | Task Board, Delivery Coordination, Mission Triage, Volunteer Impact |
| **Government Officer** | **Yes** | `RESQ07` (or click "Apply demo passkey") | Incident Command Map, Broadcast Alerts (SMS/Siren), Audit History |
| **System Admin** | **Yes** | `RESQ07` (or click "Apply demo passkey") | User Role Management, System Diagnostics, Security Audits |

## 🛠 Available Scripts

- `npm run dev` — Launches the Vite development server with Hot Module Replacement (HMR).
- `npm run build` — Compiles production-ready bundle into `resq_vnext/dist`.
- `npm run preview` — Previews the production build locally.

## 🎨 Dual Theme System

- **Dark Mode**: Deep Obsidian Space Navy (`#070d14`) with cyan and amber tactical accents.
- **Light Mode**: High-contrast Porcelain Mist (`#f3f6f9`) with accessible slate text and oceanic teal accents.
- Toggle between modes anytime using the **Sun / Moon** icon in the header bar.
